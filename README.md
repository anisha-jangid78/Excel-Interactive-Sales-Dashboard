📊 Excel Interactive Sales Dashboard

📌 Project Overview

The Excel Interactive Sales Dashboard is a data visualization project created using Microsoft Excel to transform raw sales data into meaningful business insights. This dashboard helps users analyze sales performance, compare targets with achievements, and monitor regional sales trends through interactive charts and filters.

The project demonstrates how Excel can be used as a powerful business intelligence tool for reporting and decision-making.

🎯 Objective

The main objective of this project is to:

Analyze sales data efficiently

Create interactive and visually appealing dashboards

Track sales performance across different regions and sales executives

Compare targets with actual achievements

Generate business insights for better decision-making

📊 Dashboard Features

🌍 Region-wise Sales Filtering

Interactive slicers allow users to filter sales data by region for detailed analysis.

👨‍💼 Sales Executive Performance Tracking

Compare the performance of different sales executives based on revenue and targets achieved.

🎯 Target vs Achievement Analysis

Track sales targets and compare them with actual sales performance using percentage calculations and visual indicators.

📈 Interactive Charts & Visualizations

The dashboard includes:

Bar Charts

Pie Charts

Line Charts

KPI Indicators

These visuals help users quickly understand sales trends and business performance.

⚡ Dynamic & User-Friendly Interface

The dashboard updates automatically when filters or slicers are applied, making it easy to explore insights interactively.

📖 Project Workflow

📥 Step 1: Data Collection

Imported raw sales data into Excel.

🧹 Step 2: Data Cleaning

Removed duplicates, handled missing values, and formatted the dataset properly.

📊 Step 3: Data Analysis

Used Pivot Tables to summarize and analyze sales data.

🎨 Step 4: Dashboard Creation

Designed an interactive dashboard using charts, slicers, and formatting tools.

📈 Step 5: Insights Generation

Generated meaningful business insights from the visualized data.
